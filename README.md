# Readme
## South Wales and South West Channel and Scope Strategy

This document is an attempt at centralising and documenting the evolving strategy for this regional area's use of:

- [Channels](Channels.md)
- [Regions](Regions.md)
- [Traffic Management](Traffic-Management.md)

## What This Document Isn't

This document is not an attempt to dictate what we do but rather document what people are doing and some useful configuration strategies.

This whole area has become surprisingly contentious of late what with the [Meshcore Split](https://blog.meshcore.io/2026/04/23/the-split) fragmenting the discussion and heated debate about how to deal with increasing traffic volumes affecting reliability. Several contradictory suggestions have been put forward, from minor tweaks and configuration, blocking of all un-scoped traffic though to full blown independence from the main mesh by changing frequency. While I obviously have opinions, I want to keep out of the weeds here and keep this document as a useful starting point for people connecting to MeshCore as it is in the region.

This document is also not intended as comprehensive documentation of the all relevant MeshCore features, that's better done by the official documentation on the main [MeshCore site](https://meshcore.io) and [Discord](https://discord.com/channels/1495203904898728149/1495203905804701898).
